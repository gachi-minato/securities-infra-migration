# 🏢 大手証券会社 インフラ更改支援

> 大手証券会社におけるオフィス環境全般のインフラ更改支援ポートフォリオ

---

## 📋 プロジェクト概要

| 項目 | 内容 |
|------|------|
| **クライアント** | 大手証券会社（顧客先常駐） |
| **期間** | 2020年5月 〜 2022年4月（約2年） |
| **役割** | 基盤メンバー |
| **チーム規模** | リード2名・メンバー8名・プロパー15名 |
| **プロジェクト規模** | 全国規模（タブレット約15,000台・プリンタ約5,000台） |

**概要**  
ユーザー向けオフィス環境全般（サーバ／タブレット／プリンタ）のインフラ更改支援。  
全国規模の端末更改において、要件定義から導入・運用までをサポート。

---

## 🖥️ 技術スタック

| カテゴリ | 技術・製品 |
|---------|-----------|
| **OS** | Windows Server 2008 / 2012 / 2016、Windows 10 / 11 |
| **環境** | Azure AD |
| **ツール** | VMware vSphere Client、Tera Term |

---

## 🎯 担当業務

### 1. Windows Server 運用テスト
- Active Directory（AD）の構築・運用テスト
- プリンタサーバーの構築・運用テスト
- SCCM（端末管理ツール）の運用テスト

### 2. 全国規模の端末更改（Windows 7 → 10 移行）
- タブレット 約**15,000台**の入れ替え
- プリンタ 約**5,000台**の入れ替え
- キッティング・台帳管理・情シス対応

### 3. 運用改善・障害対応
- ログ監視・解析
- batスクリプト作成による運用自動化
- 障害対応・エスカレーション

---

## 🛠️ 習得スキル

### インフラ技術
- **Active Directory**：構築・運用テスト・ログ解析
- **SCCM**：端末管理・配布設定
- **Azure AD**：端末管理・SSO拡大
- **プリンタサーバー**：構築・運用テスト
- **VMware vSphere**：仮想環境操作

### 運用・自動化
- batスクリプト作成による運用改善
- ログ監視・解析・障害対応
- キッティング・台帳作成・情シス対応

### プロジェクト管理
- 打ち合わせ・設計構築依頼・納期管理
- 受入テスト・関係者調整・品質確保
